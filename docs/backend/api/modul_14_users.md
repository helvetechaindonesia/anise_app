## 👥 Modul 14: Manajemen User & UI/UX
*Prefix:* `/api/users`
- `GET /`: List seluruh pengguna (Khusus TU/Admin).
- `POST /`: Tambah *user* baru.
- `PUT /{id}/roles`: Mengganti jabatan *user*.
- `PUT /preferences`: Menyimpan preferensi tema (Dark/Light mode).

> Catatan: Dokumentasi ini dihasilkan dari blueprint endpoint.md. Tambahkan detail request/response secara spesifik di sini saat API mulai dikembangkan.
