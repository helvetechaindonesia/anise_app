## 📨 Modul 11: Surat Menyurat
*Prefix:* `/api/letters`
- `GET /incoming`: Daftar surat masuk (Khusus TU).
- `GET /outgoing`: Daftar surat keluar.
- `POST /outgoing`: Membuat arsip surat keluar baru.

> Catatan: Dokumentasi ini dihasilkan dari blueprint endpoint.md. Tambahkan detail request/response secara spesifik di sini saat API mulai dikembangkan.
