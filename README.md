# Anise App

Sistem Informasi Terpadu (Mobile & Web) untuk Manajemen Sekolah.

## 🚀 Teknologi yang Digunakan
- **Frontend:** Flutter (Mobile Android/iOS & Web)
- **Backend:** Laravel (PHP)
- **Database:** PostgreSQL
- **Server Environment:** Docker (Opsional) / Laragon

## 📂 Struktur Proyek
- `/frontend` - Kode sumber aplikasi Flutter (UI, State Management, API Integration).
- `/backend` - Kode sumber aplikasi Laravel (API, Database Migrations, Models).
